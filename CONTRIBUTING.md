# Contributing to web-map-doc

This repository is the documentation for the [MapML.js](https://github.com/Maps4HTML/MapML.js)
polyfill implementation of [Map Markup Language](https://maps4html.org/MapML-Specification/spec/).

It is used for work in the [W3C Maps For HTML Community Group](http://www.w3.org/community/maps4html/),
governed by the [W3C Community Contributor License Agreement (CLA)](http://www.w3.org/community/about/agreements/cla/).

**Everyone who contributes to this repository must be a CLA signatory.** Join the
Community Group and sign the CLA before opening a pull request; contributions from
non-signatories cannot be accepted.

By contributing to this repository, you license your contribution to the
Community Group and to the public under the
[W3C Software and Document License](http://www.w3.org/Consortium/Legal/2015/copyright-software-and-document)
(`W3C-20150513`), as set out in [LICENSE.md](./LICENSE.md). This applies to
documentation, example code, demonstration pages and assets alike. You retain
copyright in your contribution.

If you are not the sole contributor to a contribution (pull request), please identify all
contributors in the pull request comment.

To add a contributor (other than yourself, that's automatic), mark them one per line as follows:

```
+@github_username
```

If you added a contributor by mistake, you can remove them in a comment with:

```
-@github_username
```

If you are making a pull request on behalf of someone else but you had no part in designing the
feature, you can remove yourself with the above syntax.

## Third-party material

Do not add third-party code or assets to this repository without recording the
required notices in [NOTICE](./NOTICE). The `static/dist/` directory is a
synchronized copy of the MapML.js build and should not be edited here.

If you have suggestions or want to open a pull request for improved documentation,
it's a good idea to open an issue and discuss with the community in advance.
